### 2026-08-18 — A presentation page for Volocal, set in the application's own two faces

`README.md` is written for somebody who has already decided to look at the
repository. Somebody deciding whether to install the application wants three
other things, in Czech: what it gains them, what it looks like, and what it
does badly. That is what `docs/site/index.html` is — one page, no build step,
opens from disk or from anywhere a static file can be served.

**The copy is not new.** Every sentence on the page is lifted from
`README.cs.md` — the owner's own wording, in the same formal address the
interface uses. Writing a second version of the same claims is how two
descriptions of one product drift apart; the page quotes rather than
paraphrases, so a change to the Czech readme is the one place to make it.

**The values are the application's, not a new palette.** Ground, panel, ink,
petrol, the note yellow and the brand triad are the numbers from
`src/css/01-base.css`, and the two typefaces are the two the program is set in:
Geist on the interface, Literata on the transcript and the leading paragraphs.
The font files are copied out of `node_modules/@fontsource-variable/` into
`docs/site/fonts/` with their OFL licences beside them, latin **and** latin-ext,
because without latin-ext Czech has no háčky.

**The window on the page is drawn, not photographed.** There is no screenshot in
the repository, and a landing page whose product shot is a stock image of a
laptop says nothing. So the window is HTML: title bar, the mark, a transcript of
two speakers, a note pinned to 39:06, a word the transcription was unsure of, and
a player. It plays — the words highlight in order, the clock and the waveform
follow, and **clicking a word moves the playhead to it**, which is the one
interaction the whole product exists for. Without JavaScript the transcript is
still there in full; only the highlight is missing.

**The mark closes to `olo`** in the header and opens again under the pointer,
the movement from `docs/prototypes/volocal-olo.html` and the timing from
`Brand.tsx`. The nine outlines are copied from `src/brandArt.ts` character for
character. That file warns what happens when the letterforms are redrawn and the
copy is not: the mark starts writing itself beside its own outline. The same
warning now applies to this page, and nothing on it will report the drift.

**What is on the page that the readme does not lead with:** the section *Na
rovinu*, which carries the readme's own list of what Volocal does not do well —
approximate word times, two voices talking over each other, panels, one
recording at a time, an unencrypted archive — set at the same type size as the
list of what it does well. A presentation page that whispers its limits in
6 pt grey is doing the opposite of what that list is for.

The interrupted-download caveat from the readme is the one item left out: 1.2.15
resumes interrupted downloads, so as a limitation it now reads as a warning
about something that was fixed.

**Where it is not.** Nothing publishes it — no Pages workflow, no domain, no
link from the readme. It is a file in the repository waiting for a decision
about where it should live.

Files: `docs/site/index.html`, `docs/site/fonts/` (four woff2 and two licences).

Verified: the file is clean UTF-8 with no replacement characters and balanced
`div`, `section` and `span`; `npm run build` is green and untouched by this,
since nothing outside `docs/` changed. A self-contained copy — the four fonts
inlined as data URIs — was published for the owner to look at in a browser,
which is the check that matters for a page nobody can test by reading it.


### 2026-08-18 — The page is rebuilt out of the application, because the first one was invented

The owner's verdict on the entry above was that the design was dreadful, and he
named the two faults exactly: **the product shot was fabricated instead of being
built from the application's own tokens, and the brand animation was not the one
that exists** — neither the tuning prototype's nor `Brand.tsx`'s, but a
simplified redraw. Both are the same fault, which is inventing a second version
of something the repository already holds.

**What replaced the drawing.** `docs/site/app-shot.css` is the application's own
stylesheet — `src/css/01-base.css` through `05-later.css`, concatenated in the
import order of `src/styles.css`, that order being load-bearing — mechanically
prefixed with `.shot` so the program's rules cannot reach the page around them.
`docs/site/scope-app-css.py` does the prefixing and is kept beside it: when the
application's CSS changes, the page's copy is regenerated rather than edited.
`:root` blocks are left global on purpose, so the page and the window are drawn
from one set of tokens.

The markup inside those windows is the DOM the React components emit, class for
class: `.detail-header`, `.player` with its `.play-ring`, `.shortcuts`,
`.segment`/`.word`, the `.sidebar` cards, and on the archive screen
`.archive-drop-zone`, `.library-bar`, `.row.running` with its `.progress` and
`.live-text`. Two windows, at the size the application actually has — 1180 × 744
— scaled to the column rather than reflowed, so the proportions stay the ones on
a real screen.

**One thing the invented version got factually wrong**, and it is worth writing
down because it is the kind of error inventing produces: it marked a single word
as uncertain. Uncertainty is a property of a **segment** — `confidence <
CONFIDENCE_THRESHOLD && !verified` — drawn as a dotted red underline under the
whole `.segment-text`, with the hover-revealed `.segment-actions` beside it. The
only per-word marks are `.word.corrected`, `.word.hit` and `.word.sounded`.

**The brand.** `docs/site/brand.js` and `brand.css` carry all three states out of
the repository rather than around it: the wordmark that holds five seconds and
closes to `olo`, the mark that writes itself with the pen and then blinks and
smiles, and the mill it becomes while a transcript runs. Outlines, pen paths and
the smile generator are copied from `src/brandArt.ts` character for character;
the timings are `Brand.tsx`'s, including `rotate(90deg) scale(.84)` rather than
the prototype's unscaled mill, which is the bug 1.2.15 fixed. All three appear
where the application puts them: the wordmark in both headers, the mill in the
archive's drop zone because that window shows a transcript running, and the face
writing itself once at the foot of the page.

**The one addition to the brand CSS**, and it is a page-only safety net: the
closed state fades `v` and `cal` as well as sending them out of frame. The travel
is in the drawing's user units and the box is in CSS pixels, so at
`--wordmark-unit` above 1 — the page header runs at 1.25 — the leading edge of
`c` can come to rest inside the closed box. Caught in a headless render, and it
is a real 1.25-scale artefact rather than a rendering one; the application, which
never scales the mark, is unaffected and unchanged.

**The playback is not a picture of playback.** The waveform is painted with
`PlaybackControls.tsx`'s numbers — 2 px bars every 7 px, centre-anchored, ceiling
0.82, the played part in the accent colour up to `handleRatio` — over the span
`usePlayerGeometry` measures. The words sound in order, the ring fills, the clock
counts, and clicking a word moves the playhead, which is the one interaction the
whole product exists for. The amplitudes are the single invented thing left on
the page, generated from a fixed formula so they never change between loads, and
the footer says the recordings are made up.

**The copy** is written to what the reader gets, in Czech, and deliberately
without the translated marketing vocabulary: no *řešení*, no *umožňuje vám*, no
*intuitivní*, no *offline*, no *exportovat*. Eight benefits ordered by what
decides a person rather than by what is technically interesting, the three
occasions the application touches the internet, and the list of what it does
badly set at the same size as the list of what it does well.

Files: `docs/site/index.html`, `app-shot.css`, `brand.css`, `brand.js`,
`page.js`, `scope-app-css.py`, `bundle.py`, `fonts/`.

Verified: rendered headless at 1360, 520 and in the dark palette, and read at
each. Three faults were found that way and fixed — pins standing on the words
they point at, the closing headline inheriting the body's line height, and the
`c` above. `npm run build` is green; nothing outside `docs/` changed.


### 2026-08-18 — Three corrections the owner made from the screen

**The mark was rising and shrinking instead of being cropped.** The page's own
reset carried `img, svg { max-width: 100% }`, and on the wordmark that is fatal:
as the box closes from 82 px to 36.49 the svg obeys the box and *scales*, so the
whole word shrinks — and keeps its aspect ratio, which lifts it in its line. The
closing is a crop, not a resize. `max-width` now belongs to `img` alone.

It also explains a mark left in the entry above: the leading edge of `c` standing
inside the closed box, which was blamed there on `--wordmark-unit` above 1. That
diagnosis was wrong. The letters were not travelling out of a fixed drawing, they
were being squeezed into a shrinking one, and every measurement of the transforms
agreed with the stylesheet while the render did not. With the reset fixed, the
travel clips exactly as it does in the application.

**And so the fade that was added for it is gone.** `.wordmark.closed` no longer
sets `opacity: 0` on `v` and `cal`; the closing is the shipped variant B and
nothing else — the outer letters leave the frame, nothing fades. The page header
also runs the mark at the application's own size rather than 1.25, and the host
takes `.header-brand-mark`'s 4px/2px rather than the prototype's roomier hit
area. Both windows now stage the mark exactly as `Brand.tsx` does: five seconds,
one second to close, half a second to open under the pointer.

**The window's title bar was invented.** It carried the publisher's mark and the
words *Volocal — archiv*. Neither exists: `src-tauri/tauri.conf.json` gives the
window the title **`volocal™`**, the icon is `src-tauri/icons/app-icon.svg`, and
`ZnackarnaMark` sits in `Brand.tsx` deliberately unimported — the publisher's
drawn mark was taken out of the interface on the owner's word and putting it in a
picture of that interface says something untrue about the product. The title bars
now carry the window's own icon and its own title. The mark stays in the page
footer, where the publisher is signing their own page rather than the program.

**The sample recording is a corporate meeting**, which is what the owner asked
for: budget, capacity for Q3, escalation, action points. The uncertain segment is
a plausible mishearing rather than a joke — *revalance portfolia* for
*rebalancu portfolia* — and the archive's live text, file names and notes belong
to the same meeting. Written down because it is the one part of these windows
that is not the application's own: the interface is real, the recordings are not,
and the footer says so.
