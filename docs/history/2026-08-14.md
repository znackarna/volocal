# 2026-08-14

### 2026-08-14 — Three tabs back up to five, because three did not help

Yesterday's entry ends with Settings at three tabs — `Přepis`, `Aplikace`,
`O aplikaci`. Jakub opened that arrangement and turned it down in one sentence:

> Ty tři karty nepomáhají. Karta vzhled by měla být zvlášť. A O aplikaci bych
> dal Informace a Aktualizaci bych dal zvlášť.

That is the reason for this change, and it belongs in the record: nothing was
measured, nothing broke — the person the screen is for looked at it and said the
grouping does not answer the question he arrives with. So the grouping changed
and only the grouping. **Every control the simplification removed stays
removed**, because those were dead (`Hledání změn mluvčího`, whose setting no
Rust code reads), harmful (`Počet mluvčích`, which silently overrode `Nevím`),
or derivable from a neighbour (`Řádkování`, `Sledovat složku`). None of that was
about tabs.

**The tabs are `Přepis`, `Vzhled`, `Složky a zálohy`, `Aktualizace`,
`Informace`.**

- `Přepis` is untouched: the model, the recording's language, the speakers, the
  language editing, the dictionary, the band saying what is downloaded, and
  `Pokročilé`.
- `Vzhled` is the appearance card taken back out of `Aplikace` — interface
  language, theme, transcript type and size, and the live sample.
- `Aktualizace` is the check, `Co je nového`, `Stáhnout a nainstalovat` and the
  automatic-check switch, lifted out of the About page. It is the one thing on
  this screen that is neither a setting nor a fact: it is an errand, one press
  of which closes the application and starts an installer. It sat under the
  licence list, which is the last place a reader looking for a new version
  looks.
- `Informace` is what `O aplikaci` was, minus the updates: what the application
  is, what it can do, and what it stands on. Nothing on it can be pressed.
- `Aplikace` is `Složky a zálohy`. **This is the one decision the owner did not
  make for us.** With appearance gone, what was left under that name is the
  recordings folder, the watched folder, the archive's backups with export and
  import, and — on an ordinary installation — the portable copy. Not one of them
  is what anybody would look for behind the word `Aplikace`, and a label that
  does not describe its contents is how the seven tabs got their names in the
  first place. The new one names both halves of what is there: the two folders,
  and the copies you go to once something has already gone wrong.

**Nothing moved between cards.** Every card is the same card with the same
contents; only which tab draws it changed. The one component change is that
`About` no longer takes the four update props — the update block is rendered by
the new `settings-card-updates` section instead.

**The tab names in the code changed with the visible ones**, so `application`
became `files` and `appearance`, `updates` and `about` stand beside them. The
last open tab is remembered in `localStorage` under `settings-tab`, and the
guard that was already there is what makes a rename safe: a stored name that is
not one of `SETTINGS_TABS` opens `Přepis` rather than an empty panel. Every
machine that opened Settings yesterday has `application` in there and will land
on `Přepis` once.

**Every card on every tab has an `order` rule**, including the two tabs that
hold a single card. Alone the number changes nothing; without it, the next card
put beside them takes `order: 0` and jumps above whatever asked for 1 — which is
precisely the defect written up yesterday about the recordings folder.

**Two keys were retired and two added.** `settings.tab.application` is gone from
`cs`, `en` and `sources.json`; `settings.tab.files` and `settings.tab.updates`
are new; `settings.tab.about` keeps its name and says `Informace` / `Information`
now. The appearance tab is labelled from `settings.appearance.title` — the card
that fills it already carries that word, and a second key holding the same word
is a second thing to keep in step. The updates card does the same in the other
direction, taking its heading from `settings.tab.updates`, exactly as the
transcription card takes its own from `settings.tab.transcription`.

- Files: `src/Settings.tsx`, `src/css/04-settings.css`,
  `src/locales/cs/settings.ts`, `src/locales/en/settings.ts`,
  `src/locales/sources.json`.
- One spacing rule moved with the block: `.about-updates` carried 22 px as the
  last band of the About card, where it followed a panel. As the whole of its
  own card it follows a heading, so it takes the 24 px `h2 + .field` and
  `h2 + .about-abilities` already take, written as
  `.settings section > h2 + .about-updates`.
- Verified: `npx tsc --noEmit`, `npm run build` (which runs `i18n:check`,
  `docs:check`, `tsc` and `vite build`), `npm test` 132. `i18n:check` required
  the three reworded or new English strings to be approved against their Czech —
  *Information*, *Folders and backups*, *Updates*, each read against its source —
  and the fingerprint left behind by `settings.tab.application` was deleted from
  `sources.json`.
- Not verified by machine: the screens. What to press is all five tabs at both
  window widths, the update check on `Aktualizace` (the button, the release
  notes dialog, the automatic switch), and Settings opened on a machine whose
  `settings-tab` still says `application`.
- **Left undone**: two tabs hold exactly one card each, so `Vzhled` and
  `Aktualizace` each carry a heading repeating the tab above it. Dropping the
  heading would make them the only cards in Settings without one, and inventing
  a second sentence for each would be words for the sake of the layout. It is
  visible and it is small; if it grates, the answer is a card that earns the
  tab, not a special case in the stylesheet.
- Also left, from yesterday and still true: 13 unused `wizard.*` keys from the
  wizard rebuild, which belong to that change rather than this one.
