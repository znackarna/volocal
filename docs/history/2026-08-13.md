# 2026-08-13

### 2026-08-13 — Two clicks on *Zálohovat teď* in one second reported a broken archive

Found by pressing the button quickly in the running application:

```
output file already exists: Error code 1: SQL error or missing database
```

Nothing was broken. The stamp in a backup's name is accurate to the second —
`volocal-2026-08-13-004512.db` — and the button re-enables the moment the first
copy is written, so a second click inside the same second aims at a name that is
already taken. `VACUUM INTO` refuses to overwrite, and its refusal arrived on
screen wearing the words *SQL error or missing database*, which is the last
sentence anybody should read about an archive that is perfectly fine.

Fixed where the name is made, not where the copy is written: if a file for this
second is already there, it is the copy this call would have made, and it is
returned. What was asked for is a backup of now, and there is one.

Two fixes deliberately not made:

- **Widening the stamp.** `backup_stamp` parses exactly `0000-00-00-000000`,
  `list_backups` orders by that text, and the rotation reads the day out of it.
  Every backup already written on every machine is in that shape.
- **Overwriting.** `back_up`'s own comment says it refuses to clobber so that a
  timestamped name can never land on an older copy. That is worth keeping, and
  this case is the one time the name is not an older copy's.

  both return the same path and that one file exists rather than an error; plus
  `cargo fmt`, `clippy -D warnings`, `cargo test` (176 passed, 2 ignored).

### 2026-08-13 — The archive card, as its owner arranged it

Three changes to yesterday's import and export, all his, recorded because the
reasoning is his rather than mine and would otherwise be lost.

**The note above *Načíst archiv* is two sentences.** Mine was one sentence
carrying three things behind a dash and a colon. His:

> Načtený archiv nahradí ten současný. Zvukové soubory nejsou součástí zálohy.

The same rhythm he wrote for restoring in 1.0.7 — *Vybraná záloha nahradí
současný archiv. Pozdější přepisy v archivu nebudou.* A short sentence, then the
consequence. Worth writing down as a rule rather than as an edit: what the
interface says about a destructive act is two plain sentences, not one that
explains itself on the way past.

**Saving a copy is its own band.** It went next to *Zálohovat teď* first, then
beside *Načíst archiv*, and neither was right: the two archive buttons point
opposite ways and each needs its own sentence read before it is pressed. A row
here is a note and one button, which is the shape `.settings-action-row` was
drawn for — `space-between` puts a note at one end and a button at the other, so
a second button in the same row lands in the middle of them.

A wrapper class for that pair existed for about ten minutes. It is gone with the
markup that used it; a rule matching nothing is what `.diagnostics-copy` already
cost this project once.

**The block is titled *Vrátit se k záloze nebo přenést archiv*,** because it now
holds three things and the previous title named one of them.

### 2026-08-13 — Correcting entry: the caveat belongs to saving, not to loading

The entry above records the import note as his two sentences, the second of them
*Zvukové soubory nejsou součástí zálohy.* He moved it, and the move is better
than the wording was.

The two notes are now:

> **Uložit kopii archivu…** — Uloží jen texty bez zdrojové nahrávky.
>
> **Načíst archiv ze souboru…** — Načtený archiv nahradí ten současný.

What the archive does not contain is a fact about the copy being *written*, and
saying it there is saying it to the person who can still do something about it —
they are standing at a save dialog, and if they wanted the audio too they now
know to copy it themselves. Said at the load button it is a complaint arriving
too late, about a file somebody else made on a machine that may no longer exist.

And it leaves the destructive act with one sentence and one verb: *nahradí*.

Worth keeping as the rule behind both: a warning goes where somebody can still
act on it, not where it is merely true.

### 2026-08-13 — A line between going back and moving the archive

Asked for after seeing the block open: the list of backups and the two archive
buttons were three bands of the same weight, and they are not the same subject.
Above the line is going back in time, below it the archive leaving this computer
or arriving on it.

`separated` on the first of the two rows, which is the existing pair of values
for exactly this — 22 px above, 20 px below, one hairline — rather than a new
rule with new numbers.

It is deliberately a second rule on this card, and the comment by
`.settings-action-row.separated` argues against having one. Worth writing down
why it is right here anyway, or the next tidy-up removes it and is correct to by
the letter: what that comment objects to is two rules a few lines apart with a
single row of text between them, on the open face of a card. This one lands
under a list, inside a block that is folded away until somebody opens it, and
the two lines are never seen close together.

### 2026-08-13 — The portable-copy card is called *Přenosný disk*

*Kopie na přenosný disk* becomes *Přenosný disk*. The card's own description
already says what it does — *Zkopíruje aplikaci a modely na zvolený disk* — so
the heading was saying it twice, and the noun is the thing the reader is looking
for when they scan the column of headings.

It also stops competing with the archive card next to it, which since yesterday
has a button reading *Uložit kopii archivu…*. Two headings a screen apart, both
beginning *Kopie*, for two different things: one copies the whole application to
a stick, the other writes a single file of transcripts. The English follows —
*Copy to a removable drive* becomes *Removable drive*.

### 2026-08-13 — The two archive buttons are *Export archivu* and *Import archivu*

*Uložit kopii archivu…* and *Načíst archiv ze souboru…* become *Export archivu*
and *Import archivu*. They are the words he used when he asked for the feature —
*Import a export archivu?* — and the two labels now look like the pair they are,
which a verb phrase and a longer verb phrase never quite did.

The ellipses go with them. They are the convention for *this opens a dialog*,
and both of these do; the noun wins anyway, because the pair reading as a pair
is worth more here than a signal most readers have never consciously noticed.

`Ukládám…` became `Exportuji…` in the same pass. The busy state takes its verb
from the button, which is what the neighbouring pair already does — *Zálohovat
teď* / *Zálohuji…* — and *Ukládám* belonged to a button that no longer exists.
