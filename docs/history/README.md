# Change log

The reasoning behind every decision in Volocal, one file per day, moved out of
`CLAUDE.md` on 2026-08-10 because that file had grown to 630 000 characters —
four times what a session can read — and was being loaded in full before every
task. Nothing was rewritten or dropped in the move.

Read a day when you need the reason behind something you are about to change.
A correcting entry never deletes the one it corrects; it is added after it, so
the later entry wins and the earlier one still explains what was believed at
the time.

## What each day was about

**[2026-08-01](2026-08-01.md)** — Precise seeking in long VBR MP3s, and the transcription pipeline's phases.

**[2026-08-02](2026-08-02.md)** — Readable transcript blocks, the local language model — enhancing, summarising, translating — online import, and the first pass over Settings.

**[2026-08-03](2026-08-03.md)** — Interface text moved into a dictionary and the checks that keep it there; notes; the speaker-count question; the embedding model that fixed diarization.

**[2026-08-04](2026-08-04.md)** — The audit: nothing may quietly destroy work. Cancelling, backups, the dictionary page, the transcript context menu, corrections kept beside the text.

**[2026-08-05](2026-08-05.md)** — Recording from a microphone, folders, saving audio, one rule for choosing among a row, and the About tab.

**[2026-08-06](2026-08-06.md)** — The public repository, the installer's branding and Czech, the content policy, and the first speaker measurements.

**[2026-08-07](2026-08-07.md)** — Speaker recognition moved inside the application: DirectML measured, sherpa-onnx dropped, CAM++ through ONNX Runtime.

**[2026-08-08](2026-08-08.md)** — Unnamed interjections, names offered before a run, the sidebar as cards.

**[2026-08-09](2026-08-09.md)** — A folder for recordings, search inside a transcript, WebView2's own shortcuts switched off.

**[2026-08-10](2026-08-10.md)** — The hardening plan, start to finish. The log moved here; the baseline got its Windows numbers; the security documentation was made to match the code; all 21 Clippy findings fixed and CI now refuses new ones; fifteen downloads pinned and compared against a published digest; four oversized files split by what they do; the webview's access to the disk closed to one file at a time — which corrects an entry written the same morning; the interface's first tests; Vite 5 to 8; and a release candidate that has to install and run before it counts. Then the day kept going: Slobot became Volocal, identifier and all, with a migration that carries the archive over; the header took the drawn wordmark; a nested transaction that broke deleting a folder was found and fixed; and the release path got a script, a version command and documents that no longer promise there is no update check.

**[2026-08-11](2026-08-11.md)** — Volocal 1.0.0. By the end of the night an update installed itself end to end — after a release that carried the previous version's installer, and a job object that killed the installer a moment after starting it. The updater's signing key was replaced with one that has a password, which is free before the first release and impossible after it.

**[2026-08-12](2026-08-12.md)** — Every Czech identifier, class name and comment turned English, the database schema with them and a migration that carries each archive over. Five releases: 1.0.5 refused the archive it had migrated and was replaced by 1.0.6; 1.0.8 pointed the application at a folder of browser cache and was replaced by 1.0.9 and deleted. In between: a backup can be restored from inside the application, a failed start writes a report the owner can hand over, and the status dots got their colour back after being grey since 1.0.5. The day ended with one branch instead of five, and a repository cleared of dead files — and of documents that still called the product Slobot and said it had never been released.

**[2026-08-13](2026-08-13.md)** — Pressing *Zálohovat teď* twice in the same second reported *SQL error or missing database* about an archive that was fine. And the archive card arranged the way its owner wanted it: saving a copy on a band of its own, and the note about replacing an archive written as two plain sentences rather than one that explains itself. Then the day turned into the simplification: a three-second gap between the sound and the highlight that turned out to be the turbo model rather than any code, a first run that asks one question instead of four and downloads 1.2 GB instead of 6.4, and Settings taken from seven tabs and 59 controls to three tabs and two dozen.

**[2026-08-14](2026-08-14.md)** — Settings regrouped after its owner looked at yesterday's three tabs and said they do not help: `Vzhled` and `Aktualizace` stand on their own again, `O aplikaci` is `Informace`, and what was left under `Aplikace` is named for what is actually in it — `Složky a zálohy`. Only the grouping changed; every control the simplification removed stays removed. Then a sixth tab, `Nástroje`, for the other half of that subject: what is installed on this machine, where it is kept, and which files the application found. And then the decision the day was really about — one question at the beginning, *rychle nebo přesně*, written down and read everywhere it decides something: which transcription model, and how large a language-editing model is fetched the first time somebody wants a document. The acceleration control is gone and `Nástroje` says what actually ran instead; the language editor's three tiers stop claiming a quality nobody has ever measured. Then the owner at the screen, nine sentences of it: `Jazyková úprava` becomes two cards, `Menší` and `Větší`, with no switch and nothing to switch off — language editing only ever runs when somebody asks a transcript for a document. `Kde přepis běží` becomes `Výkon` and gets its choice back as two cards, `Grafická karta` and `Procesor`, with automatic as the resting state and CUDA against Vulkan decided by the drivers and never asked. Icons on all four choices, and the processor builds of both whisper and the language editor now come down on every machine, so that neither choice points at something that is not there and a broken driver has a floor. `Jazyk nahrávky` gets a card of its own. Then a screenshot with two things struck through in red, and the rule the day had written down but not applied: the card is silent when it agrees and speaks when it does not. The `Používá se` row goes, `Automaticky` becomes a switch under the cards rather than a button beside them, and with nothing left naming a build, `domain.compute.*` goes with it. Then: the by-hand list's group headings say which half of the list a component is in now that both halves hold language models, `Větší` leads the editor cards the way `Přesný` leads the model cards, and the wizard's detected-hardware panels go because the sentence above them already said it. Then two tabs named for both halves of what is on them — `Jazyk a vzhled` and `Výkon a modely` — with `Jazyk aplikace` given a card of its own beside the appearance card, and `Technické podrobnosti` folded away at the foot of its tab the way `Pokročilé` is at the foot of `Přepis`. And last, the tabs cut to one word each on the rule that a row of single words reads as a row of peers and that the single word must be a superset rather than a truncation — then `Výkon` given a tab of its own, making seven: `Přepis` · `Rozhraní` · `Výkon` · `Nástroje` · `Soubory` · `Informace` · `Aktualizace`. With it, the model list stops being an inventory and becomes an offer: picking a model that is not downloaded fetches it, and `settings.model` follows the file rather than the click. And at the other end of the day, the transcript screen: speaker recognition leaves the language-editing dialog for a button of its own — it never was language editing, no model is loaded and nothing is rewritten — and the card it vacates becomes `Vlastní prompt`, an instruction the reader writes themselves. The instruction is kept once per installation and saved as it is typed; its answers are kept per recording, keyed by the wording that produced them, in a table of their own so that regenerating or discarding the improved transcript cannot take them with it. A fourth tab in the preview window shows them, the empty field cannot start a run, and the dialog says in a line what `SECURITY.md` says at length: the model runs in this computer and nothing leaves it. And the day ended in the module listing: every row that can be deleted has a bin, and the ones that cannot wear a lock with a tooltip saying which of the two reasons it is — something is using it this moment, or the application never recorded which files are its own. Both were real: the lock had been asking whether a model is *chosen* rather than whether it is *working*, and `ffmpeg` and `deno` unpack into the shared programs folder with nothing to say which files are theirs, so an installation now writes down what it wrote and deletes by that list. Deleting the chosen model is allowed and never leaves the settings naming a file that is gone. With it: the download ring becomes the mini player's, the group headings get their space above rather than below, the online-video component is named for the audio it actually fetches, the button says where it goes, and the card states what this machine holds — how many components of how many are offered, and the space they take, measured off the disk rather than added up from the catalogue's hand-written sizes. One pair of words for that set wherever it is named, and the interface-language note says `okamžitě`. Then the dialog's grey bands, which were not two grounds under one scrim: the veil is a child of the wizard's `<main>`, so the rule centring that screen's content had clamped it to 620 px and left the window undimmed either side of it. And the listing takes the settings column's 720 px, on the owner's ask — same selector as the veil, two faults, one habit of centring everything a screen contains. And the first run itself, rebuilt: the wizard stops being a full screen that replaces the archive and becomes a larger dialog over it, because the application drawn behind it says *you have arrived* where a screen said *you are blocked*. Two cards stacked rather than side by side, each with room for a real sentence — the name of the choice, the model and what the reader gets in the catalogue's own words, and what it costs on this machine in minutes and megabytes. Above them, one line saying what was actually found here, which meant teaching the application to read its own memory: `total_memory_gb` in `tools.rs`, rounded to the number on the box and reporting nothing at all rather than guessing. And `doporučeno` stops being a badge and becomes a reason, argued from that same fact. The four time estimates are still unmeasured — a first run has no model and no recording to measure with, and deriving them from the new detection would have been a fabricated model wearing the authority of an arithmetic — so the note under the cards now says in as many words that they are a rough estimate and not a measurement.
