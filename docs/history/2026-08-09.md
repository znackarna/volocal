# Change log — 2026-08-09

Moved out of `CLAUDE.md` on 2026-08-10, word for word. Why, and the
other days: [README.md](README.md).

### 2026-08-09 — The audio the application makes has a folder of its own

- A microphone take existed nowhere else and lived in
  `%APPDATA%\cz.znackarna.whisp\microphone\`, a place nobody browses to and
  which the interface never named. Online imports were worse: `online-media\`
  under a UUID.
- Added: `Složka pro nahrávky` in Settings → Soubory, beside the watched
  folder. Microphone takes and the audio pulled out of an online video both go
  there, under readable names. Default is `recordings` beside the archive —
  a new name rather than the historical `microphone`, which stopped being true
  the moment videos went in too. Nothing is moved by an upgrade: every row
  holds an absolute path, so what is already there keeps playing where it is.
- Added: `Kopírovat přidané soubory`, off by default. On, a file added by hand
  is copied in and the row points at our copy, so deleting the original loses
  nothing. Deliberately a copy and not a move — the file is the owner's. A copy
  that fails stops the import and says so rather than quietly filing the
  original: the answer to "is my audio safe here" must not be *sometimes*.
- The online download still gets a scratch directory of its own, now
  `.download-<uuid>` inside that folder, because yt-dlp names the file from the
  video's title and the only way to learn what it wrote is to give it a
  directory and look. The finished file is moved up — `rename` first, a copy as
  the fallback for a recordings folder on another disk — and the scratch goes.
- **This is the answer to "shouldn't the playback proxy save me if I delete the
  source", and the reason it is not.** The proxy exists only for MP3, is a
  second-generation lossy encode, and is keyed on the source's own fingerprint
  precisely so it can be thrown away. Promising audio survival on top of a
  cache would keep that promise for half the recordings.
- Files: `src-tauri/src/{db,main,online_import}.rs`, `src/Settings.tsx`,
  `src/types.ts`, `src/locales/{cs,en}/{settings,errors}.ts`.

### 2026-08-09 — A missing source falls back to its cached proxy

- Changed: when the source file is gone and a playback proxy is still sitting
  in the cache, playback uses it instead of reporting nothing. Found by prefix
  rather than by fingerprint — the fingerprint is computed from the source's
  metadata and there is no source left to ask.
- Recorded at the call site and repeated here because it will be misread: this
  is a rescue, not a guarantee. `copy_imports` is the guarantee. Do not let the
  existence of this fallback become the reason not to turn that on.
- Files: `src-tauri/src/{main,tools}.rs`.

### 2026-08-09 — Finding a word inside one transcript

- Added: Ctrl+F, or the magnifier at the end of the playback strip, opens a
  find bar over the reading column. Escape closes it, Enter and F3 step to the
  next match, Shift reverses. Every match is tinted and the one being stood on
  takes the accent; the transcript scrolls to it.
- Highlighted in place rather than filtered. The archive's search filters
  because there the reader is picking a recording; here they are reading and
  correcting, and a block without the ones around it is no use.
- **Diacritic-insensitive and case-insensitive**, so `reknu` finds `řeknu`.
  Not a nicety in Czech: the diacritics are exactly what somebody typing
  quickly leaves out, and a search that misses because of a háček is one
  nobody tries twice.
- Known limit: a query containing a space marks no words. The words are
  separate elements and a phrase runs across them; the block still counts as a
  match and can be travelled to.
- `F3` now means two things by context — next match while the bar is open,
  next uncertain spot while it is closed. Deliberate, and flagged rather than
  done quietly.
- The bar keeps clear of the sidebar, which is what `--postranni-sirka` was
  extracted for: the panel's width was a literal in the grid and was about to
  become a second literal in this offset.
- Files: `src/Detail.tsx`, `src/styles.css`, `src/locales/{cs,en}/detail.ts`.

### 2026-08-09 — The browser underneath is switched off

- Ctrl+F opened WebView2's own find bar — a strip in the title area, drawn by
  Windows, searching the DOM. Right-click offered Reload, Print, View source
  and Inspect. Neither belongs to this application.
- Changed: `AreBrowserAcceleratorKeysEnabled` and
  `AreDefaultContextMenusEnabled` are both off, set once on the main window
  beside `allow_microphone`. A key WebView2 no longer handles falls through to
  the page, which is what lets this application's own Ctrl+F and F3 work
  instead of racing it. Clipboard keys are a separate setting and are untouched.
- Cost, stated because it is real: no right-click paste in a text field.
  Ctrl+V still pastes. A context menu of our own for fields would be its own
  piece of work.
- Every failure is logged and none is fatal: an old runtime that has no
  `ICoreWebView2Settings3` keeps the browser keys rather than refusing to
  start.
- Files: `src-tauri/src/main.rs`.
