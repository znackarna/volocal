# 2026-10-03

### 2026-10-03 — Dead code, finished plans and the Vercel workflow removed

An over-engineering audit of the whole repository; this entry is the part that
changes nothing a user can see.

**Removed files.** `refactor_codex.md`, `docs/hardening-plan-2026-08-10.md`,
`docs/cleanup-plan-2026-08-28.md` and `docs/reviews/` were plans and prompts
whose work is finished and recorded here. `docs/prototypes/volocal-olo.html`
was the brand animation's tuning prototype; `Brand.tsx` overrides it.
`probe/ort-dml/` answered whether DirectML works, and `ort` with `directml` is
in `src-tauri/Cargo.toml` since. `.github/workflows/site.yml` was disabled on
2026-10-02, when the page moved to the company's server. The site README's
*Publishing* section and the `site-server/` comments now describe the server
instead of that workflow, and the analytics paragraph names Umami.

**Removed code.** Everything `tsc --noUnusedLocals` found: about thirty unused
imports and the leftovers of earlier splits in `App.tsx`, `Settings.tsx`,
`Detail.tsx` and `Library.tsx` (the audio export constants, `sameCandidates`,
`THEMES`, `themeChoice`, `COMPUTE_CHOICES`, `COMPUTE_MODULES`, the compute
locals now owned by `PerformanceSettings.tsx`). Three waveform helpers in
`player.tsx` had no caller. The three `app.audioFormat.*` keys lost their last
reader and are gone from both dictionaries. `.choice-cost`, `.choice-reason`
and `.save-menu-group` had no element. `noUnusedLocals` is now on in
`tsconfig.json`, so this does not grow back.

**Scripts.** `i18n.mjs` takes plural categories from `Intl.PluralRules` instead
of a hand-written table, and `i18n:clear` is gone — English is the only second
language.

**Verified.** `npm run build` (i18n and docs checks included) and `npm test`,
335 tests, as before. Rust untouched in this commit.

### 2026-10-03 — Small Rust duplicates folded, `hex` dropped

`hex` had two callers, both `hex::encode(digest.finalize())`; `format!("{:x}", …)`
does the same with what `sha2` already returns, so the dependency is gone. The
command line's `clock()` was `export::format_duration` letter for letter and
calls it now. `enum Source` had one variant left since the GitHub-release
search was removed; it is a plain `source: String`, never stored and never read
by the window. `tools.rs` carried two identical recursive `size_of` helpers; both
sweeps use `download::directory_size`, which also stops following anything that
is neither a file nor a folder — only the reported number of bytes reclaimed can
differ.

Looked at and kept: `benchmark_compute` (its comment keeps it deliberately as the
only instrument for timing a backend); the unread `Settings` fields, because
`vad` and `cluster_threshold` have no `serde(default)` and an older copy of the
application reading settings written without them would lose them all to
defaults; the duplicated block in `restore_backup`/`import_archive`, which is
the path that protects the archive and is not to be refactored unseen.

**Verified.** `cargo fmt --check` only — there is no Windows toolchain on the
machine this was written on, so compiling, `cargo test` and clippy are left to
`Checks` on `dev`.

### 2026-10-03 — The rest of the audit that cannot change behaviour

**Done.** `reported(x.map_err(anyhow::Error::from))?` became a plain `?` in
`commands/folders.rs` and `commands/backups.rs`: `rusqlite::Error` and
`std::io::Error` already convert to `UserMessage` through `unknown_from!`, so
the code is the same and only the detail text loses anyhow's `{:#}` cause
chain. `recorderTime` is gone; the recorder's clocks use `formatTime`, which is
the same `m:ss` and shows `h:mm:ss` past an hour instead of `61:00`. The setup
wizard's F3 hint uses `Filled` instead of splitting the sentence by hand.
`docs/site/app-shot.css` was regenerated with `scope-app-css.py`; it had fallen
behind `src/css`.

**Looked at and kept.** The two `step()` helpers: without them the calls no
longer fit on one line and `cargo fmt` spreads each over seven. The
`execCommand` clipboard fallback: it exists for WebView builds that expose the
API and refuse it (2026-08-11), which cannot be ruled out from here.
`app-shot.css` stays committed: generating it at deploy means changing the hook
on znackarna-server2. Not started, because each changes how the interface
behaves and needs checking by hand in the running application: the date
picker (#7, with #21), `Select.tsx` (#9), `useDialog` on `<dialog>` (#10),
`popover` for the outside-click menus (#14), `Tooltips.tsx` (#29); and the
`node:http` site server (#4), which changes the deploy.

**Verified.** `npm run build` and `npm test`, 335 tests, `cargo fmt --check`.
Not compiled: this machine has no C linker, so `cargo check` is left to
`Checks` on `dev`.

The audit itself, the state of each item and a brief for whoever continues are
in [docs/audit-2026-10-03.md](../audit-2026-10-03.md).
