# 2026-10-03

### 2026-10-03 — A proposal for an interactive screen in `volocal-cli`, not started

The owner asked for a terminal interface to `volocal-cli` that does not look
dry, and for a team to design its look and what it does. Four roles worked on
it: product and interaction, visual design, Rust architecture, and a critic who
reviewed the other three against the code and this repository's rules.

**What came out.** `docs/tui-plan.md`, the proposal, and
`docs/prototypes/volocal-tui.html`, eleven screens drawn on a character grid in
both terminal themes, with the mark animating. Nothing in the program changed.
The proposal keeps every decision of `docs/cli-plan.md`: no microphone, no
playback, no hand editing, the window unchanged, the six commands unchanged.
Seven questions are left for the owner, the first being whether bare
`volocal-cli` in a terminal should open the screen.

**Decisions taken inside the team, and why.**

- *The look is the window's, carried into cells.* Colours come from
  `src/css/01-base.css`, brought to 4.5:1 as text by the rule behind
  `--accent-solid`; the `olo` mark and the publisher's mark are rasterised into
  braille from `src/brandArt.ts` and `ZnackarnaMark`. The first drafts drew the
  publisher's mark as `▲●■`; the owner saw at once that it was lopsided, because
  those three characters take their sizes from the font. It is now two rows of
  braille, one size for all three shapes.
- *Motion only while something works.* The visual draft had the idle face blink
  and smile as in the window; the critic pointed out that this contradicted
  "ticks only while something moves". The idle face is still; blinking is left
  for later.
- *Keys that a Czech keyboard can type.* The first key map used `1–4` and
  `[ ] { }`, which on Czech QWERTZ type `+ěšč` or need AltGr; it also gave `n`
  and `t` two meanings each. The map in the proposal has one meaning per key,
  and none needs AltGr.
- *A stopped first transcription keeps nothing.* The first draft said a stopped
  run "keeps what was done". The engine writes blocks only when it saves
  (`transcription/mod.rs`), so a first transcription cancelled earlier goes back
  to untranscribed. The question before stopping says so.
- *The second-language question is the window's own,* in its words
  (`detail.secondLanguage.missing`), and only for someone who chose in the window
  to be asked.

**Found on the way, not fixed here.**

- Closing the console during `volocal-cli transcribe` leaves the recording
  marked as transcribing: `stop_on_ctrl_c` cancels and returns at once, and
  Windows ends the process before the engine writes the status. Step 0 of the
  proposal fixes it.
- The window's start-up tidy-up (`recover_interrupted`) would mark a run in
  progress in the command line as failed. Question 6 of the proposal.
- `backendCodes()` in `scripts/i18n.mjs` reads only the top level of
  `src-tauri/src`, so a message code added under `transcription/` or
  `commands/` would not be checked against the dictionary. All present today
  exist.

**Verified.** The architecture was measured in a scratch crate: ratatui 0.30.2
with crossterm 0.29.0 added about 0.3 MB to a release binary and needs Rust
1.88, the repository's minimum; a Windows-target check and clippy passed. The
critic checked the proposal's claims against the code (file and line in the
review) and the new crates' licences. The gallery renders without console errors
in Chromium, and every mockup line adds up to its grid width. `npm run
docs:check` and `npm run i18n:check` pass.

The work is on the branch `claude/great-pasteur-2mwh1t`, based on `dev`, because
the session that made it was given that branch; it moves to `dev` as a
fast-forward.

Files: `docs/tui-plan.md`, `docs/prototypes/volocal-tui.html`,
`docs/history/2026-10-03.md`, `docs/history/README.md`.

### 2026-10-03 — Correction: no full-screen interface; the commands print better instead

The owner read the proposal above and turned the full-screen part down: the
command line deserves a better picture of its progress, but bare `volocal-cli`
should not start a program of its own inside the terminal. What he wants is the
six commands, printing better.

So `docs/tui-plan.md` became `docs/cli-look-plan.md`, rewritten, and the gallery
became `docs/prototypes/volocal-cli-look.html`, redrawn as terminal sessions
of the real commands. The new proposal: when a stream is a terminal, `list`,
`show`, `status` and `export` lay out and colour what they print today, and
`transcribe` prints whisper's blocks as they come with a live block of phases,
a bar and an estimate beneath them, collapsing into a summary. In a pipe, a
file or with `NO_COLOR` the output stays byte for byte, the help is unchanged,
and no command or flag is added.

What survives from the first proposal: the palette and its four colour levels,
the four-cell mill, the ASCII set for the old console, the ported rule that a
phase never moves backwards, and the two fixes to `transcribe` (closing the
console waits for the cancel; whisper ends with the CLI). What goes: ratatui,
the alternate screen, the key map, the mouse, the `terminal` namespace.

It needs no new crate: `anstyle-query`, already in `Cargo.lock` through `clap`,
switches on VT sequences in the Windows console, and the `windows` dependency
already has the console feature for the width. About 600–900 lines with tests,
against 3 500–4 000 for the full screen.

Files: `docs/cli-look-plan.md` (was `docs/tui-plan.md`),
`docs/prototypes/volocal-cli-look.html` (was `volocal-tui.html`),
`docs/history/2026-10-03.md`, `docs/history/README.md`.

### 2026-10-03 — The command line looks better in a terminal, and says so in Czech

Built from `docs/cli-look-plan.md` at the owner's word, with two conditions of
his: the system's language when the program has it, and in no case anything
that could break the desktop application.

**What a person sees.** In a terminal `list` lines its columns up with a mark
for each state, `--search` groups its hits under their recording with the
match highlighted, `show` and `status` are quiet label columns and a
checklist, `export` says `✓ Uloženo`, and errors are a sentence with `✕`.
`transcribe` prints whisper's blocks as they come and keeps a live block under
them, the done phases with their times and the running one with the mill, the
position, a bar and an estimate, collapsing into a summary at the end. Czech on
a Czech system (`GetUserDefaultUILanguage`), English otherwise,
`VOLOCAL_LANG=cs|en` to choose.

**What a script sees: nothing new.** Each command asks first whether its
stream is a terminal and only then gives its data to the new code; otherwise
the old code runs, unchanged. The errors became a `Problem` type so that they
could also be said in Czech, and `the_english_is_what_it_always_was` holds the
English of each to the old text. Checked by building the program before and
after and running both under Wine on one sample archive, piped: fifteen
commands, output and exit codes identical. `NO_COLOR` in a terminal gives the
plain output too.

**What the window sees: nothing.** The new code lives in
`src-tauri/src/bin/volocal-cli/` (the program became a folder: `main.rs`,
`look.rs`, `styled.rs`, `live.rs`). The engine changed by one word,
`die_with_this_process` made `pub` so the command line can call it, and its
doc comment. `Cargo.toml` is untouched: the console calls come from the
`windows` features the command line already had, and the language call is
declared in the program rather than added as a feature. The dictionaries are
untouched; the command line reads `src/locales/cs/` as it already read
`src/locales/en/`.

**Two fixes to `transcribe`, found while designing this.** Closing the console
during a run now waits for the stop to be written down (up to 4 s of the 5
Windows allows), so the recording is no longer left marked as transcribing; and
whisper is tied to the command line's process and ends with it.

**One trap, worth knowing.** The Czech dictionary files carry a second table,
`csErrorsContext`, with translator notes under the same keys; read whole, the
notes overwrote the messages, and `status` printed *VAD = detekce řeči…*
instead of the sentence. `first_table` reads only the first, and a test says
so.

**Colour.** The terminal's own sixteen colours rather than the window's
palette in truecolor, as the proposal had it: the user's theme decides what
they look like, so the output reads on a dark and a light background alike,
which a palette tuned for one cannot promise without asking the terminal.

**Verified.** Under Wine for the Windows target: `cargo clippy --all-targets
-D warnings` clean, 25 tests of the command line pass, the engine's tests give
the same 315 passes before and after (three fail under Wine on both, for want of
ffmpeg and ONNX Runtime). `cargo fmt`, `npm run build`, `docs:check` and
`i18n:check` pass. `docs/cli.md` gained the terminal behaviour under *For
scripts* and an accurate line on what Ctrl+C keeps; the help itself is
unchanged. Not yet seen: the live block on a real Windows console during a real
transcription.

Files: `src-tauri/src/bin/volocal-cli/{main,look,styled,live}.rs` (main.rs
was `src-tauri/src/bin/volocal-cli.rs`), `src-tauri/src/lib.rs`,
`docs/cli.md`, `docs/cli-look-plan.md`, `docs/history/2026-10-03.md`,
`docs/history/README.md`.
