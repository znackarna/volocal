# Volocal over-engineering audit, 2026-10-03

Read-only audit of `main` at `dc6825f`. Nothing was changed. Ranked by lines saved, biggest first.

1. `shrink` `docs/site/app-shot.css` (about 4,600 lines) is a generated copy of `src/css`, and it is already out of date: regenerating it gives a 75-line difference. Generate it at deploy with `scope-app-css.py` and stop committing it. [docs/site/app-shot.css]
2. `delete` Planning and prompt docs that are finished, and whose reasoning is already in `docs/history`: `refactor_codex.md`, the hardening and cleanup plans, and `docs/reviews/`. About 2,000 lines. [refactor_codex.md, docs/*-plan-2026-*.md, docs/reviews/]

4. `native` The website server is a full Next.js app that only serves files from disk. A ~100-line `node:http` server can replace it, removing `next`, `react`, `react-dom` and a 965-line lockfile. The deploy hook on znackarna-server2 would have to change with it. [site-server/]
5. `delete` The DirectML test project. Its question is answered: `ort` with DirectML is now in the app's `Cargo.toml`. About 970 lines including its lockfile. [probe/ort-dml/]
6. `delete` `benchmark_compute` and `BenchmarkResult`, plus their `errors.benchmark.*` texts. Nothing calls the command. About 135 lines. [src-tauri/src/commands/benchmark.rs:14-143, src-tauri/src/lib.rs:622]

9. `native` `Select.tsx`. Use `<select>` with `appearance: base-select`. About 140 lines. [src/Select.tsx]
